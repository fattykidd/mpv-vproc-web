    Integrations
    Unfolded Circle Remote
    Lets an Unfolded Circle Remote find and control vproc on your network. While off, nothing is announced and no port is open.
    System settings

    vproc's own settings. They start out as set in .env; a value changed here is saved by vproc and used instead, and Reset goes back to .env. Changes are saved straight away and take effect when you press Apply, which restarts vproc in a few seconds.

    Settings only .env can change

    Docker uses these before vproc starts. Change them in .env, then run docker compose up -d.

    Tools

    A frame grab saves the current picture as a PNG: as displayed (scaled and tone-mapped) or as captured. Diagnostics collects the status, settings, versions and recent log into one file to attach to a bug report; it never includes the API token.
