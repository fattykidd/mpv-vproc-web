# Shaders

GLSL shaders that picture settings can load into mpv. They are copied here unchanged from their
upstream projects, with their licenses, so the container works offline.

| Folder | Shader | Author | License | Source |
|---|---|---|---|---|
| `cfl/` | Chroma from Luma (CfL) prediction: `CfL_Prediction.glsl`, `CfL_Prediction_Lite.glsl` | João Chrisóstomo (Artoriuz) | MIT (`cfl/LICENSE`) | https://github.com/Artoriuz/glsl-chroma-from-luma-prediction at commit `066dff9` |

To update a shader, copy the new upstream files over the old ones and update the commit above.
